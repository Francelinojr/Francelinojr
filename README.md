## Projetos em destaque

### [Análise de taxas de suicídio — 1985 a 2016](https://github.com/Francelinojr/Visao-geral-das-taxas-de-suicidio-1985-a-2016)

Análise exploratória por país, sexo, faixa etária e geração, utilizando Python, Pandas, Seaborn e Jupyter Notebook. O projeto demonstra organização de dados, identificação de padrões e construção de visualizações para apoiar a interpretação dos resultados.

### [Análise de dados da Netflix](https://github.com/Francelinojr/Analise-de-Dados_da_Netflix)

Projeto de análise exploratória sobre o catálogo da Netflix, com foco em preparação dos dados, investigação de tendências e apresentação visual dos principais achados.
