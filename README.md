## Sobre mim

Sou estudante de **Ciência de Dados e Inteligência Artificial na UFPB**, em João Pessoa, com interesse em análise exploratória, visualização de dados e aprendizado de máquina. Tenho experiência prática com manipulação, limpeza e interpretação de dados usando Python e ferramentas do ecossistema de dados.

Atualmente, estou ampliando meus conhecimentos em desenvolvimento de software, bancos de dados e fundamentos de machine learning por meio de projetos práticos.
